# Una pequeña sorpresa 💜

Página estática de cumpleaños, optimizada para celular. Abre `index.html` para verla. No requiere instalación ni compilación.

## GitHub Pages

Subir estos archivos a un repositorio público. En Settings → Pages, seleccionar Deploy from a branch, rama `main`, carpeta `/ (root)`. Guardar y esperar el despliegue. Usar el enlace que entregue GitHub para el QR.

La página es pública. `noindex` y `robots.txt` piden a los buscadores no indexarla, pero no son controles de acceso.

## Punto de regreso

La etiqueta `version-gatos-traviesos` conserva la versión aprobada `2ae1530`, anterior a los GIFs. Para regresar, recuperar los archivos de esa etiqueta en un nuevo commit y publicar, conservando el historial y la dirección del sitio. La primera versión está en `88b77fa`.
